CLI, AI Coding Agent（AI 編碼代理）:
- GitHub Copilot CLI（在終端機打 copilot 啟動）
- Claude Code CLI（在終端機打 claude 啟動）
- Codex CLI（在終端機打 codex 啟動）
- Antigravity CLI（在終端機打 gemini 啟動，由舊版 Gemini CLI 升級而來）
- Gemini CLI。(以取代為 Antigravity CLI)

MODULE:
- Claude 模型 (Anthropic 公司開發)
- Gemini 模型 (Google 公司開發)
- OpenAI (GPT) 模型
- Codex 模型 (OpenAI 專門為寫程式優化的引擎系列)


---

GitHub Copilot CLI
- 可以切換多模型。
- 付錢給 GitHub，在裡面打指令就能自由把大腦切換成 OpenAI、Claude、Gemini 或 Codex。

Claude Code CLI
- 只能使用 Claude 模型。
- 不允許切換到 OpenAI 或 Gemini。

Codex CLI
- 只能使用 OpenAI 自家的核心與 Codex 模型。
- 不允許換成 Claude 或 Gemini。

Antigravity CLI
- 預設且最推薦使用的是 Gemini 模型。
- 但允許進階開發者自己接 API 轉接器去連 Claude。
